# Medium Tier

Multi-file applications that require project structure, testing, and real engineering decisions.

## What "Medium" Means

- **Scope:** 5-10 files, 500-1500 lines of code
- **Complexity:** State machines, async I/O, database integration, testing
- **Dependencies:** Multiple packages, dependency management
- **Time budget:** 30 minutes per task
- **What it tests:** Project architecture, testing discipline, error handling at scale, dependency management

## Tasks

| # | Name | Focus | Files | LOC |
|---|---|---|---|---|
| 01 | Web Crawler | Async I/O, HTML parsing, dedup, scheduling | 5-8 | ~800 |
| 02 | REST API with Database | ORM, migrations, auth, testing | 6-10 | ~1000 |

Each task lives in its own directory under `medium/`. See the individual README for full details.
