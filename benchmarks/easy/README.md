# Easy Tier

Small, focused tasks that test basic coding ability. These are the "hello world" of real engineering.

## What "Easy" Means

- **Scope:** 1-3 files, under 200 lines of code
- **Complexity:** Linear logic, no complex state machines, no concurrency
- **Dependencies:** Standard library or one well-known package
- **Time budget:** 10 minutes per task
- **What it tests:** Syntax, API knowledge, error handling, following specifications
